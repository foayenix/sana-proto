# SANA Vision Prototype

A comprehensive Flutter demonstration app showcasing SANA's 5-10 year vision for integrated, evidence-based complementary and alternative medicine (CAM) healthcare.

## 🎯 Purpose

This prototype is designed to demonstrate SANA's complete vision to investors, stakeholders, and partners. It showcases all planned features using realistic dummy data to illustrate the platform's potential impact on healthcare delivery, evidence generation, and patient outcomes.

## ✨ Key Features

### 1. **SANA Health Graph (360° Wellness Dashboard)**
- Large circular SANA Health Score (0-100)
- Visual wellness status badges (Needs Support → Stable → Thriving → Optimal → Radiant)
- Biological age vs chronological age comparison
- AI-generated Top 3 Levers with personalized recommendations
- Radar chart showing 6 wellness dimensions:
  - Physical Health
  - Mental Wellbeing
  - Emotional Balance
  - Social Connection
  - Sleep Quality
  - Energy Levels
- Data sources integration tracking
- 12-month timeline with annotated events

### 2. **AI Journal (SIRM - SANA Insight & Reflection Model)**
- Daily reflection input
- 4 AI personas to choose from:
  - 🧘 Compassionate Therapist
  - 📚 Wise Philosopher
  - 🎨 Creative Poet
  - 🔬 Evidence-Based Coach
- Personalized AI responses based on selected persona
- Journal history with mood tracking
- Tag-based organization and search

### 3. **Enhanced Practitioner Profile with SANA Index**
- Prominent SANA Index Score display (0-100)
- Detailed score breakdown:
  - ✅ Verified Credentials (20 points)
  - 📊 Treatment Volume (20 points)
  - 📈 Measured Outcomes (40 points)
  - 📝 Data Quality (10 points)
  - ⭐ Client Satisfaction (10 points)
- Condition-specific outcome data with charts
- Treatment modalities and effectiveness
- Client reviews and ratings
- Peer comparison metrics

### 4. **Evidence Dashboard (Practitioner View)**
- Practice insights and analytics
- SANA Index tracking over time
- Outcome analytics by condition
- Client improvement rates vs platform average
- Client cohort analysis with demographics
- Evidence generation contribution metrics
- Research-grade data point tracking

### 5. **Research Portal (Institutional Access)**
- Dataset explorer with available research datasets
- Visual query builder for custom data requests
- Data quality indicators and completeness scores
- Multiple export formats (CSV, FHIR, REDCap)
- GDPR Article 89 compliance
- Published research using SANA data
- Collaboration opportunities

### 6. **Enterprise Dashboard (NHS/Corporate Integration)**

#### NHS Social Prescribing Tab:
- Active referrals tracking
- Bi-directional referral flow visualization
- ROI calculator showing NHS cost savings
- Patient satisfaction and adherence metrics
- Integration status with NHS systems
- Connected GP practices map

#### Corporate Wellness Tab:
- Employee enrollment and engagement metrics
- Company wellness trends over time
- Popular services usage charts
- Department wellness comparisons
- Business impact metrics (sick days, productivity, retention)
- Benefits platform integration status

### 7. **Home Dashboard (Client View)**
- Today's wellness summary
- Quick action buttons (Log symptoms, Book, Journal, Message)
- Upcoming appointments
- Recent activity feed
- Wearable data integration (Apple Health, Oura Ring, etc.)
- Recommended practitioners carousel

### 8. **Supporting Features**
- Appointments management
- Profile and settings
- Wearable device integrations
- Notifications
- Help and support
